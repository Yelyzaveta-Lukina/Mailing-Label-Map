User Guide

How It Works

  1. Select an area using Draw or Radius
  2. View addresses with Selected Addresses
  3. Export data (CSV or Excel)
  4. Create labels using Draft Labels
  5. Print using Avery 5161 label paper

Select an Area

  • Draw : Draw a rectangle or polygon around the desired area.
  • Radius : Set a distance, press Apply, then click on the map.

View & Export Addresses

  • Click Selected Addresses to see results.
  • Use filters and sorting to organize data.
  • Download CSV or Excel using the Download button.

Create Mailing Labels

  • Click Draft Labels.
  • Select Owners, Residents, or Both.
  • Click Create Labels to generate printable labels.

Printing Tips (Avery 5161)

  • Paper size: Letter
  • Scale: 100% / Actual Size
  • Do NOT use “Fit to page”
  • Recommended browsers: Chrome or Edge
  • Map snapshot: Before printing, make sure the selected area is clearly visible on the screen. Avoid zooming in too close or too far out — keep the full selection comfortably framed so streets and addresses are readable. The app uses your current map view to generate the snapshot on the first print page.

Troubleshooting

  • No addresses selected? Make sure you pressed Apply (Radius) or finished drawing.
  • Labels misaligned? Confirm Avery 5161 paper and 100% print scale.
  • Draft Labels disabled? You must select an area first.
